# Tutoring Java Memoization

A dynamic-programming exercise that counts valid arrangements of black and white cells on a board.

## Learning goals

- recursive problem decomposition
- memoization and dynamic programming
- unit testing combinatorial algorithms

## Run

Run `mvn test` from the repository root.

## Publication note

This is a new, history-free educational snapshot containing only a generic algorithmic exercise.
